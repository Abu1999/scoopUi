# <img src="src-tauri/icons/128x128.png" width="42" alt="ScoopUI 图标"> ScoopUI

为 [Scoop](https://scoop.sh) 包管理器打造的 Windows 桌面图形界面。

基于 Tauri 2 + Vue 3 + Rust，覆盖 Scoop 的日常使用与运维场景：环境初始化、应用管理、离线全量搜索、软件源与镜像、下载加速、配置集、环境迁移。

> 当前版本：**v1.0.0**（正式版）

## 功能特性

### 已安装应用

- 当前 Scoop 环境的应用统一列表
- 可更新徽标、锁定（hold）标记；支持单应用更新/卸载/锁定
- 「全部更新」一键更新全部可更新应用

### 商店与搜索

- 离线全量索引（解析本地软件源全部清单），输入即时出结果
- 列表 / 卡片两种视图（**默认卡片**），结果详情（版本、描述、主页、许可证）
- 安装：可选指定版本、实时日志与取消

### 软件源管理

- 添加（支持已知软件源与自定义仓库地址）、删除、更新 Scoop 与软件源
- 软件源镜像一键切换（官方 GitHub / gitee 镜像 / 201704 代理）

### 镜像与下载加速

- `URL_PROXY` 下载加速开关、连通测试与出口 IP 地理判定
- 代理（`proxy`）设置、aria2 一键安装与并发参数

### 配置集（Profile）

- 另存当前状态：软件源（含源地址）+ 应用 + 下载加速设置
- 与当前状态差异对比（缺少/多余软件源与应用、源冲突、设置变化）
- 一键应用：写入设置、差集加源、安装缺失应用、可选卸载多余应用（默认关）；单步失败不中断（失败步骤显示原因，其余继续执行），完成后自动刷新差异
- 导入 `scoop export` 原生 JSON（自动识别）或导出自家格式 JSON

### 环境迁移

- 扫描注册表中非 Scoop 安装的软件（含系统组件过滤）
- 与本地清单按置信度匹配（高：名称精确；中：可执行文件名；低：描述词重叠）
- 已在 Scoop 管理的条目自动隐藏（含旧全局安装目录）
- 引导接管：用 Scoop 安装，可选「安装前先卸载旧版」（默认开）

### 其他

- 深色模式：跟随系统 / 浅色 / 深色，重启保持
- 任务流式日志抽屉，失败给出中文建议（网络/镜像/权限/冲突）
- 任务并发：下载/安装应用时，仍可对其它应用执行更新/锁定/卸载/安装，以及切换镜像、保存代理、配置集管理等无影响操作；同一应用或全局操作（维护、软件源增删、删除/迁移环境）需等待任务结束（后端会校验并给出提示）
- 软件源增删与配置集应用新增源后，自动刷新商店离线索引
- 安装后自动注册应用自带钩子（如 git 的右键菜单、文件关联、凭据管理器）
- 一体化环境：Scoop 与 UI 同装同删，默认位于安装目录内，可在设置中迁移
- 维护操作：清理下载缓存、清理旧版本、checkup、重置 shims

## 环境要求

- Windows 10 及以上（x64）
- [Scoop](https://scoop.sh) 环境（无需预装：首次启动可一键初始化，或接入已有安装）
- [Rust 工具链](https://rustup.rs)（rustup + MSVC Build Tools）
- Node.js 20+ 与 pnpm
- WebView2（Windows 10 通常已内置）

## 首次使用（自动初始化 Scoop）

安装包内置 Scoop 与 main 软件源快照（浅克隆，含 `.git`）。首次启动若未检测到 Scoop，会显示引导页：

- 「一键初始化（内置，无需下载）」：离线释放内置快照到目标目录（默认 `<安装目录>\scoop`，可修改），可选创建 `scoop` 命令并加入 PATH
- 「在线安装最新版」：适合网络畅通、希望直接安装最新 Scoop 的场景
- 「已经装过 Scoop？选择根目录」：接入已有安装

初始化后即可使用全部功能（软件源索引、安装/卸载/更新应用等）。装好 git 后可用「更新 Scoop 与软件源」获取最新内容；无 git 时安装应用不受影响。

内置快照随 ScoopUI 版本刷新（`scripts/build-scoop-bundle.ps1` 重新打包），引导页会显示快照版本。

**环境清理**：被 ScoopUI 接入的 Scoop 环境会写入 `ScoopDir` 标记；卸载本应用时安装程序会询问是否连同删除该目录（含已安装应用），并清理：

- 各应用自带的 `uninstall-*.reg`（右键菜单、文件关联，如 Git Bash Here）
- 用户 PATH 中指向该环境的全部条目（`shims` 与各应用 `env_add_path` 目录）与 `SCOOP` 环境变量
- 开始菜单「Scoop Apps」快捷方式
- 旧位置 `%USERPROFILE%\.config\scoop\config.json` 中遗留的 `root_path`（本应用已不使用该文件）
- 应用自身数据：`<安装目录>\data`、`%APPDATA%\scoopui`、`%LOCALAPPDATA%\scoopui`，以及注册表 `HKCU\Software\ScoopUI` 整键

也可随时在「设置 → 运行环境」点击「删除该环境」，同样会先回放 `uninstall-*.reg`，再清理 PATH、快捷方式、`SCOOP` 与 `root_path`。单独卸载某个应用时，也会兜底清掉该应用在用户 PATH 中的残留条目。

**被占用文件的强制删除**：删除环境或卸载应用时，若文件被其他程序占用（典型如资源管理器加载的 `7-zip.dll` 右键扩展；映像映射的 DLL 无法直接删除），或应用进程仍在运行，界面会弹窗列出占用进程，确认「强制删除 / 强制卸载」后先结束相关进程（资源管理器会自动重启，桌面短暂闪烁几秒），再清理残留文件；未能删净时会列出剩余条目并可重试。安装程序卸载时遇到残留会提示手动清理路径。

## 数据目录

ScoopUI 自己的配置随程序放在**安装目录内**，与程序同装同删；仅在安装目录不可写（如只读介质）时回退到 `%APPDATA%\scoopui`。

| 路径 | 用途 |
|---|---|
| `<安装目录>\data\settings.json` | Scoop 环境目录、主题等设置 |
| `<安装目录>\data\profiles\` | 配置集文件（`<名称>.json`） |
| `<安装目录>\data\icons\` | 图标缓存 |
| `<安装目录>\data\install-scoop.ps1` | 在线安装脚本（临时产物） |

升级到本版本后首次启动，会自动把旧的 `%APPDATA%\scoopui` 下配置与配置集一次性迁入新位置（只补齐缺失文件，不覆盖）。

**Scoop 环境配置**：环境的 `config.json` 固定保存在**环境目录内**（`<环境目录>\config.json`，Scoop 便携模式；一体化部署时即 `<安装目录>\scoop\config.json`），随环境一起创建与删除。本应用只读写该文件，不再读写 `%USERPROFILE%\.config\scoop\config.json`（旧文件如仍存在，可自行删除）。

## 常见问题

**更新 git（或其他正在使用的应用）失败**

Scoop 更新应用前会检测是否有相关进程在运行。若通过本应用的终端、VS Code 等正在使用 git，会提示
`The following instances of ... are still running`。请关闭相关窗口后重试，或在独立的 PowerShell 中执行：

```powershell
scoop update git
```

**提示「Uncommitted changes detected. Update aborted.」**

你使用的 Scoop 是国内增强版（本地包含 URL_PROXY 等补丁），Scoop 自身的自动更新会因工作区改动被跳过；软件源与应用更新不受影响。

**添加软件源 / 更新提示缺少 git，或装完 git 仍提示？**

本版本起，应用内的 scoop 子进程会自动包含环境的 `shims` 目录：在商店安装 git 后**无需重启应用**即可立即添加需要 git 的软件源或更新。若仍提示需要 git，请确认 git 已安装成功（日志中下载失败会按失败上报，不再误报成功）并检查网络。

**环境迁移扫描不到某软件**

仅扫描注册表 `Uninstall` 键中登记的软件；命令行工具（如 Android platform-tools）通常没有卸载条目，不会出现在列表中。

## 更新日志

### v1.0.0（正式版）

在 0.1.x 系列基础上完成一体化、识别与稳定性收尾后的首个正式版。

- **应用识别修复**：兼容 Scoop 新版的 `scoop-manifest.json` / `scoop-install.json` 与 BOM / UTF-16 编码，`current` 联接损坏时回退版本目录——已安装列表与配置集不再「识别不到」，应用配置集后立即可见
- **一体化环境**：Scoop 环境与配置默认位于安装目录内（`<安装目录>\scoop`、`<安装目录>\data`），同装同删；环境配置固定为环境内 `config.json`（Scoop 便携模式）
- **彻底删除**：删除环境 / 卸载应用时回放 `uninstall-*.reg`、清理 PATH / 快捷方式 / `SCOOP` / `root_path`；被占用文件（如资源管理器加载的 7-Zip 扩展）支持「强制删除」——自动定位并结束占用进程（含自动重启资源管理器）；安装程序卸载遇残留会提示
- **任务并发**：下载 / 安装应用时仍可操作其它应用与无影响设置（镜像、代理、配置集管理等）；全局操作互斥并给出中文提示；「修改位置 / 删除该环境」在任务中禁用，防止环境损坏
- **配置集**：单步失败不中断（失败步骤显示原因，其余继续执行），完成后自动刷新差异；新增软件源后自动刷新商店索引
- **商店**：默认卡片视图；软件源增删与更新后自动刷新离线索引
- **git 体验**：安装 git 后无需重启应用；命令失败不再误报成功（退出码正确传递），失败给出中文建议

## 非目标

- 不支持多套 Scoop 环境并存/切换
- 不自动提权（UAC 触发时仅提示）
- 不代搬旧软件的用户数据（提供引导）
- 无托盘常驻与开机自启（后续可评估）
- 暂不提供多语言（界面为中文）
